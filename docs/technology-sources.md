# Tecnologias: origem da seleção

Revisão dos repositórios em 8 de outubro de 2026. A lista descreve tecnologias presentes nos projetos; não atribui níveis de domínio nem anos de experiência. Dependências auxiliares não são uma alegação de entrega em produção.

C, C++ e VS Code foram preservados da apresentação já existente no [README do perfil](https://github.com/PHnsilva/PHnsilva), como tecnologias declaradas pelo autor; não foram inferidos dos manifestos revisados.
